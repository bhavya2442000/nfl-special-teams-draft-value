# Question 5: How Should Drafted-Specialist Success Be Defined?

## Answer

No single threshold captures specialist value. The project reports six definitions:

1. Appeared in at least one NFL game
2. Reached 48 career games
3. Reached 80 career games
4. Recorded positive weighted AV
5. Earned a Pro Bowl selection
6. Earned an All-Pro selection

The 48-game threshold is approximately three traditional 16-game seasons of career volume; it is not a true first-three-season outcome. Reporting all six definitions prevents the conclusion from depending on one arbitrary cutoff.
